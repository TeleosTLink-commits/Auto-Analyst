## Template Usage Notes

### How to use this template:

1. **Copy this entire template** for each new case
2. **Fill in all bracketed [items]** with actual data
3. **Check boxes** as you complete each analysis
4. **Be specific** - don't just say "bad diagnosis", explain WHY
5. **Show your work** - customers pay for your expertise
6. **Be professional** - this is a legal document if disputed

### Time-Saving Tips:

- Create text snippets for common findings
- Build a library of diagnostic code explanations
- Save pricing research for common parts
- Keep shop ratings updated in real-time

### Quality Checklist:

Before sending report:
- [ ] All customer data correct?
- [ ] Diagnostic codes researched?
- [ ] All 4 filters completed?
- [ ] Clear verdict stated?
- [ ] Specific action steps provided?
- [ ] Proofread for typos?
- [ ] Professional tone throughout?
